# 验证范围

## 3.18.4+mixue.3

默认答案提示（hintsOnly=True），自动填答与自动提交均默认关闭。所有填入路径均要求显式开启 autoAnswer 且关闭 hintsOnly；提交还要求另行开启 autoSubmit。浏览器面板与文档使用统一名称，并附 DISCLAIMER.md。

新增回归验证实际发行模板及缺省配置均为提示模式、默认手动查询不填入或提交、关闭提示但未开启填答时不操作、开启填答但未开启提交时不提交。既有真实浏览器模拟测试保留显式开启后的填答／提交验证。

## 3.18.4+mixue.2

恢复官方 3.18.4 的智慧树 skip_questions 任务，增加智慧树课程域名限制；学习通仍使用独立 runner，蜜雪与 Polymas 实现未修改。

新增四项离线浏览器回归：旧版弹题点选前两个选项并关闭、已答题不再点选、学习通与 Polymas 不受影响、新版智慧树弹题保留上游人工等待。

测试页面由本机拦截请求并返回模拟内容，不向真实课程提交答案。既有测试覆盖平台分流、目录、进度、播放、账号隔离、学习通电子书及蜜雪模拟服务。

发布包 release-info.json 记录打包时实际测试数量和冻结程序检查结果。离线通过不代表所有学校页面兼容，蜜雪真实题库／AI 服务尚未验证。

不发布私人日志、截图、课程进度、访问参数、账号、Cookie、Key、浏览器资料或机器专用路径。不会把历史测试报告当作本次修复的验证结果。
